Simplifier3D v0.4.1 — ADAPTIVE UI
===================================

Only the Geometry 3D interface layout changed.

Fixes:
- right panel is vertically scrollable as a safety net
- Actions has guaranteed minimum height, so button text is not clipped
- buttons reduced to 26..30 px high
- parameter controls reduced in height
- statistics spacing reduced
- large Mouse/editing help group removed from the right column
- editing help condensed to one short wrapped line
- right panel width: 300..350 px
- plot may shrink to 460 px
- default window: 1180 x 720
- minimum window: 900 x 600

No RDP, ARC, editing, Undo/Redo, marker, generation, export or save logic changed.
