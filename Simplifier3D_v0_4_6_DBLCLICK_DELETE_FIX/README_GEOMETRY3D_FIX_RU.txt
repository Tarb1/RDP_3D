Исправления Geometry 3D
======================
Из исходных файлов изменён только geometry3d_module.py.
Первые две страницы и их алгоритмы сохранены побайтно.

Исправлено:
1. Вставка точки: дробное время и XYZ интерполируются как на странице
   Geometria AB–BC. Удалено округление времени и ограничение участка > 1 мс.
2. Двойной щелчок завершает начатое перетаскивание и сбрасывает детектор
   пары щелчков, чтобы следующий щелчок не продолжал предыдущую пару.
3. Состояние выбора дуги передаётся до перерисовки: 3D подсветка больше
   не отстаёт на один щелчок и исчезает при выходе из выбора.
4. Обновление без Fit сохраняет пределы всех трёх осей 3D, включая масштаб.

Запуск: RUN.bat или python rdp_simplifier26.py.
Зависимости: python -m pip install -r requirements.txt.

Проверки: 8 регрессионных тестов, исходный self_test_3d_core.py,
запуск главного окна с тремя страницами. Интерфейс проверен через Qt
в режиме offscreen на Linux; ручная проверка Windows не выполнялась.
Команда тестов: python -m unittest -v test_geometry3d_regressions.
На Linux без дисплея: QT_QPA_PLATFORM=offscreen перед командой.

Дополнительное исправление: редактирование непосредственно во вкладке 3D
=====================================================================
Ранее 3D обработчики явно исключали выбор, добавление и перемещение.
Теперь: двойной щелчок по редактируемому отрезку вставляет вершину;
щелчок по вершине выделяет её; DELETE POINT удаляет выделенную вершину;
перетаскивание перемещает вершину в плоскости экрана с сохранением глубины.
Линия и другие проекции обновляются во время движения. Undo/Redo сохраняются.
Первые/последние точки и маркеры защищены от удаления как в 2D.
Вращение 3D: перетаскивание за свободное место графика.
Проверены 9 тестов, включая Qt события в 3D при двух ракурсах.
Проверка выполнена на Linux offscreen; Windows вручную не проверялась.
